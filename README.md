# TaskHub
「至高の」Todoアプリ

## 主な機能

- タスクの追加・編集・削除
- タスクの完了/未完了切り替え
- タスクのフィルタリング（全て/未完了/完了済み）
- タスクの検索機能
- データのローカル保存

## 技術スタック

- フロントエンド: React + TypeScript
- デスクトップアプリケーション: Electron
- ビルドツール: Vite

## Project Setup

### Install

```bash
$ pnpm install
```

### Development

```bash
$ pnpm dev
```

### Build

```bash
# For windows
$ pnpm build:win

# For macOS
$ pnpm build:mac

# For Linux
$ pnpm build:linux
```
